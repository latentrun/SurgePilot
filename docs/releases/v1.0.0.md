## Highlights

- Initial public release of the self-hosted SurgePilot distributed load-testing platform.
- Visual Scenario and Test Plan workflows, authenticated Workspaces, Linux Load Nodes, Debug and
  Standard Runs, Run Reports, and InfluxDB/Grafana monitoring are available in one release.
- The release uses digest-pinned multi-architecture control-plane images and native Linux `amd64`
  and `arm64` Runtime assets. A checksum-verified user-local installer provides the `surgepilot`
  lifecycle command.
- API Catalog, the PAT-authenticated public API, and Help guidance for AI agents are included.

## Install

On a supported Linux host or macOS host with Docker Desktop:

```sh
curl -fsSL https://github.com/latentrun/SurgePilot/releases/download/v1.0.0/install.sh | sh
surgepilot up
```

Follow the [v1.0.0 Quickstart](https://github.com/latentrun/SurgePilot/blob/v1.0.0/docs/site/docs/quickstart.md)
for prerequisites and first-run LAN configuration.

## Upgrade

This is the first public release, so no upgrade from an earlier SurgePilot release applies.
Automatic upgrades are not supported.

## Compatibility and breaking changes

- The containerized control plane supports Linux `amd64`, Linux `arm64`, and macOS through Docker
  Desktop.
- Load Nodes and the Taurus/JMeter Runtime are Linux-only; the supported distributions are Ubuntu
  24.04 and Debian 12.
- The interactive release setup configures HTTP for a trusted LAN. Internet-facing deployments
  require an operator-managed HTTPS reverse proxy and secure-cookie configuration.
- Breaking changes: None; this is the initial public release.
